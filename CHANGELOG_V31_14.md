# Jornada de Bia — V31.14: atualização visual

- Redesenho pastel inspirado na referência enviada: rosa, azul e cartões arredondados.
- Remoção visual do banner antigo com girassol, preservando os contadores internos para compatibilidade.
- Cabeçalho compacto “Oi, Bia”.
- Cartões de acesso rápido para Modo Bia e Modo Responsável.
- Cartões de intenção e cartões de comunicação maiores, com melhor área de toque.
- Navegação inferior para Início, Categorias/Símbolos e Configurações.
- Atualização do nome do cache do service worker para evitar servir CSS antigo após a atualização.

## Nota
Esta versão é uma etapa visual baseada na V31.13. Ela não implementa ainda a autenticação WebAuthn no servidor nem a criptografia dos dados ativos locais. Essas etapas de segurança devem ser feitas separadamente e testadas antes de publicação.
